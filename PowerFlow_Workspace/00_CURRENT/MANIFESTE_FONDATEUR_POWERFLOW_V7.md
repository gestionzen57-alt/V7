## I. CE QUE POWERFLOW N'EST PAS

PowerFlow n'est pas un système de trading automatique.
PowerFlow n'est pas un conseiller financier.
PowerFlow n'est pas un bot de signaux.
PowerFlow n'est pas une réplication d'indicateurs classiques.
PowerFlow n'est pas une analyse technique standard.
PowerFlow n'est pas une machine à décider.

Ces définitions négatives ne sont pas des disclaimers.
Ce sont des frontières architecturales.
Franchir ces frontières casse le système.

---

## II. CE QUE POWERFLOW EST

PowerFlow est un moteur de perception.

Il perçoit le flux.
Il mesure le comportement.
Il nomme l'événement.
Il alerte vite.
Il qualifie sans juger.
Il laisse le trader décider.

La distinction est totale.

Une analyse technique classique cherche à prédire.
PowerFlow cherche à percevoir.

Prédire = présumer une direction.
Percevoir = nommer ce qui se passe maintenant.

## III. LA VISION DU MARCHÉ

Le marché Forex n'est pas un graphique.
Le marché est un système vivant de forces en tension.

Les devises ne "montent" pas ou "descendent" pas.
Les devises respirent, se compriment, explosent, absorbent, résistent, cèdent.

Les mouvements naissent.
Ils se chargent avant d'éclater.
Ils se fatiguent avant de s'inverser.
Ils s'organisent en structures — leaders, followers, coalitions, antagonistes.
Ils laissent des traces dans les cycles, les densités, les angles, les zones.

Cette vision est organique.
Elle est incompatible avec les indicateurs retardés.
Elle est incompatible avec les figures chartistes figées.
Elle est incompatible avec les seuils universels non-contextualisés.

*Comment ça bouge.*

*Où ça se trouve dans l'espace de tension.*

### Niveau 3 — Densité Temporelle

Leader. Follower. Coalition. Antagoniste. Divergence. Codépendance.

Compression. Tendance. Range. Transition.

## VI. L'ALERTE POWERFLOW

Une alerte PowerFlow n'est pas un ordre.
Une alerte PowerFlow est une perception transmise.

Elle transmet :
- ce qui se passe (type d'événement)
- à quel stade (maturity)
- avec quelle fiabilité de capture (capture_quality)
- dans quel contexte de régime (regime_context)
- avec quels risques techniques (technical_risks)
- ce qu'il faut surveiller ensuite (next_watch)

Elle ne dit jamais :
- "c'est risqué"
- "attends"
- "sois prudent"
- "je ne recommande pas"

Elle expose.
Le trader filtre.
Le trader décide.

## VII. DOCTRINE ANTI-CENSURE

Une alerte précoce doit être produite, pas retenue.

Qualifier n'est pas retenir.
Exposer la maturité BIRTH n'est pas dangereux.
Signaler un EIE non encore persistant est de l'information.

Retenir une alerte par "prudence" est une forme de mensonge par omission.
Le trader perd de l'information qu'il aurait pu utiliser ou ignorer lui-même.

PowerFlow alerte.
Le trader filtre.
Cette division est la garantie de souveraineté.

**PowerFlow s'engage à :**
- voir TOUT le flux disponible

- nommer TOUT événement identifiable
- alerter sans censure, sans délai artificiel

- filtrer selon son style et sa stratégie
- configurer les leviers selon sa vision
- accepter ses décisions
- ne pas attendre de la machine ce qu'elle ne peut pas faire — décider
