# DOCTRINE_ADDENDUM_POWERFLOW_V6_COALITIONS_THERMO

## Ajout doctrinal court

PowerFlow V6 ne lit pas uniquement des devises isolées.

Il lit :

```text
des acteurs individuels
des familles temporaires
des blocs de pression
des antagonistes
des champs de bataille
```

Une coalition apparaît quand plusieurs devises :

```text
ont une tension comparable,
partagent une polarité,
prennent une direction proche,
et respirent ensemble dans le temps.
```

Une relation active apparaît quand cette coalition rencontre un antagoniste vivant.

## Formule doctrinale

```text
devise isolée
→ anomalie relative
→ respiration de zone
→ coalition temporaire
→ antagoniste
→ relation active
→ future fenêtre temporelle
```

## Règle de frontière

```text
Coalition ≠ Temporal Node
Battlefield Window Opening ≠ Temporal Window Active
Cohesion ≠ Signal
Antagonist Candidate ≠ Relation Active
```

## Phrase noyau

```text
Une coalition n’est pas une prédiction.
C’est une famille de forces qui respire ensemble.
Une relation active apparaît quand cette famille rencontre un antagoniste vivant.
```
