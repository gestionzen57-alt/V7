## 1. LAB_004_TEMPORAL_WINDOW_FRACTAL_IMBRICATION

Lab de fenêtre temporelle fractale.

Définition :

```text
Fenêtre où un node énergétique local s’imbrique dans une histoire supérieure portée par les timeframes HTF,
avec compression / étirement du temps, couche multidevise et tempo propre par devise.
```

Phrase noyau :

```text
Un node n’est pas seulement un croisement.
C’est un ancrage énergétique qui permet à plusieurs timeframes de s’imbriquer dans une histoire supérieure.
```

## 2. TEMPORAL_WINDOW_FRACTAL_IMBRICATION

Définition :

```text
Imbrication d’une fenêtre tactique M15/M5/M1 dans un contexte HTF plus large.
```

Structure :

```text
HTF_PRE_NODE_FIELD
→ M15_SCENE_BUILDING
→ M5_TACTICAL_NODE_BIRTH
→ PRICE_LAG_THEN_CATCHUP
→ COUNTER_BREATH
→ ABSORPTION
→ H4_CROSS_CONFIRMATION_LATE
→ HIGHER_STORY_FIELD
```

## 3. ENERGETIC_NODE_ANCHOR

Définition :

```text
Point d’énergie où plusieurs forces se croisent, se disjoignent ou se redistribuent.
Il peut naître en LTF, être confirmé tardivement en HTF, puis s’affirmer en amplitude sur Daily / Weekly.
```

Non-confusion :

```text
ENERGETIC_NODE_ANCHOR ≠ simple cross géométrique
```

---

## 4. HTF_PRE_NODE_FIELD

Définition :

```text
Champ HTF où les devises convergent, se rapprochent ou se pré-positionnent avant que le vrai node tactique ne soit visible en M15/M5.
```

Rôle :

```text
préparer le théâtre
donner la gravité
ne pas donner forcément le timing
```

---

## 5. H4_CROSS_CONFIRMATION_LATE

Définition :

```text
Croisement ou node H4 qui arrive après que le mouvement tactique a déjà été travaillé sur M15/M5.
```

Lecture :

```text
H4 ne donne pas forcément la naissance.
H4 confirme ou relaie une structure déjà préparée en LTF.
```

Nuance :

```text
H4 peut être confirmation tardive du chapitre précédent
et relais vers le chapitre suivant.
```

---

## 6. M15_SCENE_BUILDING

Définition :

```text
Phase où M15 raconte la scène tactique sans forcément montrer la naissance exacte.
```

Rôle :

```text
construire le scénario
montrer la compression / bascule / respiration
servir de couche intermédiaire entre HTF et M5
```

## 7. M5_TACTICAL_NODE_BIRTH

## 8. PRICE_LAG_THEN_CATCHUP

Définition :

```text
Les forces basculent avant que le prix ne paye.
```

Structure :

```text

CONFIRMATION = PRICE_PAYING
```

## 9. TEMPORAL_ELASTICITY_FIELD

Définition :

```text
Champ où le temps du marché se comprime ou s’étire pour orchestrer plusieurs comportements stratégiques dans une même fenêtre.
```

Modes :

```text

TIME_STRETCHING_PHASE
```


Mesures futures :

```text

event_density_per_window

```


## 15. FRACTAL_CONTRADICTION_FIELD

Définition :

```text
État où plusieurs timeframes racontent des phases différentes de la même histoire.
```

Exemples :

```text
LTF montre la naissance
M15 semble plat
H4 confirme tardivement
Daily porte l’amplitude longue
```

Règle :

```text
Contradiction timeframe ≠ invalidation.
Elle peut être un emboîtement de chapitres.
```
