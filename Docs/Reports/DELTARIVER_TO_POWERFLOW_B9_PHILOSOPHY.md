# PHILOSOPHIE DELTARIVER → CLÉ DE LECTURE POWERFLOW B9

**Objet :** Document court à lire avant tout travail B9.  
**But :** donner l'angle de lecture DeltaRiver transposé dans PowerFlow.

---

## 1. Phrase centrale

```text
Ne lis pas un signal.
Lis une situation.
```

Le signal seul ment souvent.
La situation raconte le film.

---

## 2. La rivière

```text
Le prix est la rivière.
Le volume est l'effort.
La delta est le déséquilibre relatif.
Le cluster est l'empreinte locale.
Le profil est la mémoire.
Le retest est le juge.
Le contexte donne le rôle.
```

---

## 3. Les huit questions B9

Avant de nommer un moment, B9 doit demander :

```text
1. D'où vient le prix ?
2. Quelle zone mémoire touche-t-il ?
3. Quel effort apparaît ?
4. Quel résultat produit cet effort ?
5. Est-ce un progrès ou seulement un mouvement ?
6. Le centre de gravité migre-t-il ?
7. Le retest confirme-t-il ou piège-t-il ?
8. Le contexte invalide-t-il le pattern local ?
```

---

## 4. Effort / résultat / progrès

```text
Effort sans résultat = absorption / frein.
Effort avec mouvement sans progrès = réaction / correction.
Effort avec mouvement et progrès = vague progressive.
```

PowerFlow ne doit pas appeler “force” un effort qui ne déplace rien.
Il doit le qualifier :

```text
pression contenue
mur limite inféré
absorption
shelf
frein
essoufflement
```

---

## 5. Le volume a deux visages

```text
Volume comme fuel : il propulse.
Volume comme brake : il arrête.
```

Le rôle n'est pas donné par le volume.  
Le rôle est donné par le résultat prix.

---

## 6. Le retest dit la vérité

```text
Break sans retest = hypothèse.
Break + retest tenu = acceptation possible.
Break + réintégration = trap possible.
Retest sur volume frais = interrogation de mémoire.
```

B9 doit traiter le retest comme une scène, pas comme un simple aller-retour.

---

## 7. Le pattern est secondaire

```text
Pin-bar, freinage, delta fort, cluster fort : rien ne vaut seul.
```

Le pattern devient utile seulement si :

```text
niveau + contexte + réaction + retest + source quality
```

---

## 8. Le microscope

```text
HTF = zone / scène / gravité.
LTF = réaction / preuve / microfilm.
Tick = empreinte brute.
```

B9 doit rester tactique :

```text
M1 n'est pas du bruit par défaut.
M1 est le microfilm.
```

Mais B9 doit qualifier la visibilité :

```text
RAW_TICK_VISIBLE
M1_BAR_PROXY
RECONSTRUCTED
READING_PARTIAL
UNCLOSED_BAR_UNSTABLE
```

## 9. Ce que B9 doit dire au trader

Pas :

```text
cluster fort
barre haussière
delta positive
```

Mais :

```text
acheteurs actifs absorbés sous zone haute
vendeurs actifs absorbés sur bas de range
breakout en attente de retest
volume frais réinterrogé
pression sans progrès
frein local ignoré par tendance
centre de gravité descend par paliers
essoufflement par projection decay
```
