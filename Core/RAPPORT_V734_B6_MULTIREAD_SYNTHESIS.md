# RAPPORT — V7.3.4 B6 MULTIREAD SYNTHESIS

## Mission

Intégrer B6 comme lecture parallèle complète du flux live.

## Correction doctrinale

B6 n'est pas un simple module Telegram. B6 est une couche de lecture tactique :

```text
Daily Journal       = journée / niveaux / sweeps / intention
Topdown Reader      = gravité HTF / plan MTF / naissance LTF
Live Brief          = tension Daily + Topdown + Live packet
B6 Order Flow Proxy = pression live récente / acceptation / rejet / absorption
```

```text

```

## Doctrine

La synthèse nomme alignement ou conflit. Elle ne décide pas.
